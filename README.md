# PowerBI-Credit-Card-Analytics-Dashboard
Interactive Power BI dashboard for analyzing credit card transactions and customer behavior, providing insights into revenue, spending patterns, customer demographics, and card performance. 

# Overview
An interactive Power BI dashboard developed to analyze credit card transactions and customer behavior. The dashboard provides insights into revenue generation, spending patterns, customer demographics, and card performance to support data-driven business decisions.

# Tools Used
- Power BI
- Power Query
- DAX
- Excel

# Key Metrics
- Revenue: 55.3M
- Transaction Amount: 44.5M
- Interest Earned: 7.84M
- Total Transactions: 655.6K

# Dashboard Features
- Quarterly revenue and transaction analysis
- Customer demographic segmentation
- Revenue analysis by card category
- Spending behavior by expenditure type
- Income, education, and occupation insights
- State-wise and gender-wise performance analysis

# Key Insights
- Blue Card category generated the highest revenue.
- Swipe transactions contributed the majority of revenue.
- Graduate customers accounted for the highest revenue segment.
- High-income customers generated significantly higher revenue than other income groups.
